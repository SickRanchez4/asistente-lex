# Punto de entrada para agentes

Este repositorio organiza el desarrollo de funcionalidades mediante Spec Driven Development (SDD).

- Empieza por [`specs/README.md`](specs/README.md) para conocer el flujo, las convenciones y los estados.
- Consulta [`specs/index.md`](specs/index.md) para localizar una funcionalidad y su estado.
- Para cambios de funcionalidad, trabaja desde `spec.md`, `plan.md` y `tasks.md`; registra las decisiones en la carpeta de la funcionalidad.
- Las instrucciones persistentes de Copilot están en [`.github/copilot-instructions.md`](.github/copilot-instructions.md).
